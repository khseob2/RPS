
# RPS 게임 사용 가이드

본 문서는 RPS 게임을 처음 사용하는 사용자를 위해
게임 진행 방법과 손 모양별 인식 팁을 제공합니다.

## 1. 게임 진행 방법

1. README의 설치 및 실행 방법에 따라 게임을 실행합니다.
2. 화면 왼쪽은 P1, 오른쪽은 P2 영역입니다.
3. 각 플레이어는 자신의 영역에 손을 위치시킵니다.
4. 카운트다운이 진행되는 동안 가위, 바위, 보 중
   하나의 손 모양을 선택합니다.
5. 카운트다운이 종료되고 판정이 완료될 때까지
   손 모양을 유지합니다.
6. 화면에 표시되는 승패 결과를 확인합니다.

## 2. 손 모양별 인식 팁

다음은 원활한 손 인식을 위한 일반적인 권장 사항입니다.

### 가위 (Scissors)

- 검지와 중지를 펼칩니다.
- 나머지 손가락은 접어줍니다.
- 검지와 중지가 서로 겹치지 않도록 합니다.
- 손가락이 카메라에서 명확하게 보이도록 합니다.

### 바위 (Rock)

- 모든 손가락을 접어 주먹을 쥡니다.
- 손가락이 어중간하게 펼쳐지지 않도록 합니다.
- 손 전체가 카메라 화면 안에 들어오도록 합니다.

### 보 (Paper)

- 모든 손가락을 자연스럽게 펼칩니다.
- 손가락이 서로 겹치지 않도록 합니다.
- 손바닥을 카메라 방향으로 향하게 합니다.

## 3. 손 인식 실패 시 해결 방법

| 확인 사항 | 해결 방법 |
| --- | --- |
| 카메라 거리 | 손 전체가 화면에 들어오도록 거리를 조절합니다. |
| 손바닥 방향 | 손바닥이 카메라를 향하도록 방향을 조절합니다. |
| 조명 | 너무 어두운 환경이나 역광을 피합니다. |
| 배경 | 손과 배경을 쉽게 구분할 수 있는 환경을 권장합니다. |
| 손 모양 | 가위, 바위, 보 중 하나의 명확한 손 모양을 만듭니다. |
| 손의 움직임 | 판정이 완료될 때까지 손을 움직이지 않습니다. |
| 플레이어 위치 | P1과 P2의 손이 서로의 영역을 침범하지 않도록 합니다. |

위 사항은 손 인식 실패를 줄이기 위한 일반적인 권장 사항이며,
카메라 성능 및 사용 환경에 따라 인식 결과가 달라질 수 있습니다.

## 4. 실제 게임 테스트 결과

실제 게임을 실행하여 손 모양과 사용 환경에 따른
인식 여부를 확인합니다.

| 테스트 항목 | 테스트 조건 | 확인 결과 |
| --- | --- | --- |
| 가위 | 검지와 중지를 펼친 경우 | 테스트 후 작성 |
| 바위 | 모든 손가락을 접은 경우 | 테스트 후 작성 |
| 보 | 모든 손가락을 펼친 경우 | 테스트 후 작성 |
| 카메라 거리 | 손의 거리를 변경한 경우 | 테스트 후 작성 |
| 손바닥 방향 | 정면과 측면을 비교한 경우 | 테스트 후 작성 |
| 조명 | 밝은 환경과 어두운 환경 | 테스트 후 작성 |

## 5. 주의 사항

- 불명확한 손 모양은 정상적으로 판정되지 않을 수 있습니다.
- 두 플레이어는 각자의 화면 영역에서 손동작을 수행해야 합니다.
- 손 인식 결과는 카메라 성능 및 주변 환경에 영향을 받을 수 있습니다.
